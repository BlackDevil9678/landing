Security details clients usually ask about

The demo is designed for local evaluation. Production client deployments should use a client-owned AI key, signed installers, and client-specific branding.

Local app storage

App configuration and connection settings are stored locally on the client machine. Sensitive values are encrypted with per-install secrets.

Read-only SQL guardrails

The backend blocks destructive SQL keywords and only permits SELECT queries for the AI query workflow.

Admin-controlled setup

Database setup, AI key configuration, and user management are protected behind authenticated admin access.

Custom client builds

Each client can receive a separate branded build with their app name, logo, data source, and AI provider settings.
