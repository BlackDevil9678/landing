Step-by-step guide
How to load the demo data

Follow these steps exactly — no technical experience needed. It takes about 5 minutes.

1

Install MySQL (if you haven't already)

MySQL is the database software that stores the data on your computer. Download the free Community version.

1. Go to mysql.com/downloads → choose MySQL Community Server

2. Download the Windows Installer (MSI) — the big blue button

3. Run the installer → choose "Developer Default" → click Next on every screen

4. When it asks for a password — write it down! You'll need it in Step 3

✅ MySQL runs automatically in the background after installation. No extra steps needed.

1. Go to mysql.com/downloads → choose MySQL Community Server

2. Download the macOS DMG package

3. Open the DMG → follow the installer → set a root password when asked

4. After install: go to System Settings → MySQL → click Start MySQL Server

⚠️ If you skip the password step, use an empty password when connecting later.
2

Install a database viewer (DBeaver — free)

DBeaver is a free tool that lets you see and manage your database with a simple visual interface. Think of it like Excel for databases.

1. Go to dbeaver.io → click Download → choose the free Community Edition

2. Install it like any normal app

3. Open DBeaver → when asked to create a new connection → choose MySQL → enter:

Host: localhost Port: 3306 Username: root Password: (the password you set in Step 1)

4. Click Test Connection — if it shows a green tick, you're connected!

💡 If you see a "driver missing" message, click Download and DBeaver will handle it automatically.
3

Load the demo data

Now you'll copy the SQL script from above and run it inside DBeaver. This creates the database and fills it with sample data.

1. Go back to the Demo Data section above and pick your dataset (Manufacturing, B2B, or Inventory)

2. Click the "Copy SQL" button — the entire script is now copied

3. In DBeaver → click the SQL Editor tab at the top → click New SQL Script

4. Click inside the blank editor area and press Ctrl+V (Windows) or Cmd+V (Mac) to paste

5. Press Ctrl+Alt+Enter (Windows) or Cmd+Enter (Mac) to run all the SQL

✅ You should see "Script executed successfully" in the bottom panel. Your demo database is now ready!
⚠️ If you see an error about "database already exists" — that just means you ran it before. It's fine, continue.
4

Verify the data is there

Before connecting the software, quickly check the data loaded correctly.

In DBeaver on the left panel, expand: localhost → Databases → you should see your new database (e.g. datalens_manufacturing_demo)

Expand it → click on any table (e.g. machines) → click the Data tab → you should see rows of sample data.

✅ If you can see data in the table rows — you're ready to connect DataLens AI!
